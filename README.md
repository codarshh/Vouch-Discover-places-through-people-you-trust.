# FriendPlace

FriendPlace is a social recommendation platform for restaurants, cafes, hotels, and other places. It combines external place metadata with trusted social recommendations from friends.

## V1 Objective
Build a working social place-discovery web app where users can search real places, connect with friends, mark places they have visited, leave reviews, and see reviews/ratings from their friends.
